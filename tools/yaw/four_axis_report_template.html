01 当前物理模型

1.1 机构、坐标与角度

本机为三臂120°布置，中心舵机通过齿轮联动三个转子，使三个推力轴沿各自切向倾转。机体采用右手系 FLU：原点为重心，+X朝机头、+Y朝机体左侧、+Z朝机架上方。M2位于左前、M4位于右前、M3位于正后；俯视逆时针／左转为正Yaw。

2.2 共同倾转分配

四个执行器（三电机、一个共同舵机）用于分配 [Fz, τx, τy, τz]。对候选舵机位置，先解3×3方程以保持竖直力和横滚/俯仰力矩，再通过有界Newton修正满足Yaw力矩；每次Yaw求解最多5次模型评估，频率200Hz。两次舵机求解之间，电机仍每500µs更新。

等倾角、水平等高臂时的解释式： τz = Σ Lᵢ Tᵢ sinδ + Σ σᵢ κᵢ Tᵢ cosδ Fz = Σ Tᵢ cosδ 若先给定各电机竖直分力： δ = atan[(τz,req − Σ σᵢ κᵢ Fzᵢ) / Σ Lᵢ Fzᵢ]

软件保留物理倾角±15°、舵机逻辑限速40°/s、非负推力和电机上限。电机解达到上限时作共同缩放并报告liftScale；缩放会损失升力和姿态控制幅值。分配受限也可能来自舵机限速或Yaw力矩残差，单个受限标志不能证明电机已顶到最大输出。

舵机50Hz硬件PWM使用整数µs指令；指令模型含80ms舵机和40ms电机一阶滞后，并考虑电机命令量化。健康检测、SA停机、失联保护及故障恢复门控保留。此前±2g原始触顶停机已通过±8g量程修正；没有绕过触顶拒绝。

4.3 Pitch / Roll 响应与系留摆动

前倾输入最大1641µs，机动期间俯仰角最高约+9.37°，方向一致。回中后约3秒内俯仰角约−4.44至+5.79°，表现为明显跨过中位的往返响应；没有持续的独立反向Pitch输入可解释全部反向姿态。它与用户描述的系留摆动相符，但缺少位置/绳角数据，尚不能将其全部归因于悬挂摆动，也不能单凭此断定姿态环阻尼不足。

横滚右向输入最大1673µs，对应Roll峰值约+10.27°；随后1370µs附近的反向输入对应最低约−5.28°。右向回中至反向操纵之间仅约1秒，不能从整段计算独立的右向回中稳定时间。最后回中后姿态仍有往返变化，报告将其作为系留条件下的恢复响应。

Pitch/Roll机动期间相对Yaw也有变化。它可能包含倾转力/反扭矩耦合、姿态换算、系留外力矩及正常反馈响应。当前没有完整姿态目标快照和绳索力测量，不把手动杆值直接线性换算为精确内环目标角，也不据此报告虚假的跟踪误差或控制带宽。

06 工程判断与下一步

本轮已支持的结论： CH1/CH4对应修正通过用户停机确认；在约250g配重持续拉紧条件下，完成约46秒空中操纵，左右Yaw及Pitch/Roll均有对应响应；未复现健康停机，2kHz主周期保持。
仍未完成的目标： 相对Yaw持向存在可量化偏差和方向不同的瞬态响应，精确锁头尚未达到既定目标。系留外力、未知真实动力参数和缺少独立航向参照，限制了本轮对自由飞行性能及模型准确性的证明。
  1. 先形成可重复的Yaw对照。 保持同一系留配置，记录不少于10秒三轴中杆，再进行左右对称、小幅、短时Yaw输入及每次不少于5秒回中；同步固定地面方向参照，标注起飞/落地。保留同一增益作为基线。
  2. 量化系留边界。 测量绳长、挂点相对重心位置、拉力方向与张力；补充视频区分机体平移摆动和姿态摆动。确认约束条件后，再讨论降低配重影响的下一轮试验。
  3. 分别校准执行器与动力。 中位附近补测双向倾角/回差及舵机动态，补充推力台或转速/电压数据；用独立惯量资料减小推力尺度与Izz之间的不可辨识性。当前不从配重悬停反推推力曲线。
  4. 针对重复问题调整。 优先验证起转配平建立、Yaw角速度跟踪和回中阻尼；每轮只改变可解释的少数参数，并保留试前试后快照。不根据本轮一次往返摆动直接增大积分或重新定义模型惯量。
