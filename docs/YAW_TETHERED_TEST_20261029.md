## 系留对动力学辨识的影响

以世界向上为正，近水平静态情况下：

```text
Fz_rotors + Ftether_z = mg
I ω_dot + ω × (Iω) = τrotors + rattach × Ftether + τrope_twist + τother
```

若配重系统接近一比一、瓶子近静止且拉力近竖直，250g配重对应约2.45N拉力，为750g机重约三分之一，所需转子竖直推力可能从7.36N降至约4.91N。这是条件估算，滑轮倍率/摩擦、绳角、配重加速度及实际张力尚未测量；不能把瓶子质量直接当成已测恒定拉力。

即使绳索竖直且固定点在中心正上方时理想Yaw力矩很小，偏斜、挂点偏心和绳索扭转仍可引入外力矩，横滚/俯仰也受到约束。因此本轮不运行自由飞行辨识，不用`mg/Fz_model`更新推力表，不拟合`Izz`、κ、阻尼或执行器滞后，不将相对IMU航向等同于独立地面方向测量。现有初值和增益保留。
