# v6：60 RPM 自旋的模型复核、控制补偿与测试准备

日期：2026-11-05。分支：`feature/cyclone-rotor-tricopter`。目标是60 RPM，即360°/s、2π rad/s、每秒一圈。[HTML版](reports/cyclone-60rpm-preparation-20261105.html)；完整普通／自旋模型见[模型文档](CYCLONE_ROTOR_MODEL.md)。v6已通过RemoteMCU下载并完成参数核对，当前开始首级15 RPM记录；尚未完成60 RPM实飞。

## 1. 结论与模型假设

v6为60 RPM准备了完整控制链路：保留普通模式持向及Roll/Pitch闭环，保留自旋时的广义驾驶坐标、Yaw率闭环、受限分配和制动归并；提高运行参数可配置范围，新增旋转差动推力的电机滞后补偿及激光相位预测。默认上电仍不授权飞行、自旋或激光，参数仅驻留RAM。

按用户确认，IMU位于旋转中心，本版取其偏心向量为零；机体750g、机臂0.5m、重心居中、无大旋转翼，仍用三台电机的小桨产生全部升力。质量、几何、机构标定沿用现有值，惯量及推力仍是初始估计，`model_verified`保持0。没有加入吊绳或配重模型，也不以限位绳的外力帮助作为控制能力。

用户提供的原作者项目作为机构与方向操纵参考，300 RPM为用户转述的作者表现。本版明确准备60 RPM，不以他机成绩替代本机验证。当前重新请求Hackaday项目页返回Not Found，因此控制背景复核使用前轮已取得的原作者页面存档；其中建议高速修改姿态闭环，但没有给出本机可直接使用的控制参数。这里继续保留姿态反馈并显式补偿滞后。

## 3. 动力学与闭环设计

### 3.1 三轴刚体与小转子角动量

普通／自旋均满足：

\[
J\dot{\boldsymbol\omega}+\boldsymbol\omega\times J\boldsymbol\omega
=\sum_i\left(\mathbf r_i\times T_i\mathbf a_i+
\sigma_i\kappa_iT_i\mathbf a_i\right)+\boldsymbol\tau_{\rm ext}.
\]

当前实现显式补偿刚体陀螺项，并使用四元数及欧拉航向率换算。若单独计入小电机桨的净自转角动量H，还存在ω×H和H的变化项；本机未测H，控制器不虚构补偿系数。新增回归将净H=±0.015N·m·s作为未告知控制器的压力扰动，该数值是测试假设，不是实测转子参数。

自旋阻尼仍写作c1·r+c2·r·|r|。运行预设保持两项为0，让现有PI承担未知稳态项，不根据他机或单次低速闭环数据猜测高转速阻力。模拟植物含未知线性0.003和二次0.0002阻尼系数；它们仅用于回归，不写入本机参数。

### 3.2 旋转差动推力的电机滞后补偿

保持一个世界方向的Roll/Pitch力矩时，该力矩在旋转机体系中以一倍自旋频率变化。40ms和80ms一阶电机滞后，在1Hz处分别产生约14.1°和26.7°相位滞后。2kHz快速更新不能消除执行器本身的这一滞后。

对慢变共同舵角下的横向力矩，采用一阶近似：

\[
\tau_m\dot{\boldsymbol\tau}_{B,\perp}
+\boldsymbol\tau_{B,\perp}=\boldsymbol\tau_{B,\perp}^{\rm cmd},
\qquad
\dot{\boldsymbol\tau}_{B,\perp}\approx
-\omega_z\mathbf e_z\times\boldsymbol\tau_{B,\perp}^{\rm desired}.
\]

于是有界命令补偿为：

\[
\begin{bmatrix}\tau_x^{\rm cmd}\\\tau_y^{\rm cmd}\end{bmatrix}
=\begin{bmatrix}1&\ell\\-\ell&1\end{bmatrix}
\begin{bmatrix}\tau_x^{\rm desired}\\\tau_y^{\rm desired}\end{bmatrix},
\quad\ell=\operatorname{clip}(s\tau_m\omega_z,-1,1).
\]

实现位于 `TricopterDynamics.h::cyclicMotorLead` 和 `NormalYawControl.h`，在自旋／制动／归并的物理力矩路径中应用；不对噪声误差做差分、不改共同升力或舵机Yaw命令，最终仍经过同一个正推力受限分配器。限幅使这项横向放大不超过√2。普通模式不应用此项，补偿比例s默认0，参数115设为1才开启。

试验将既有参数76的电机时间常数由40ms改为80ms，用于该相位补偿及执行器预测。80ms是覆盖40–80ms回归场景的调试初值，尚未进行电机辨识。最初无补偿的两倍惯量／80ms用例触发倾角保护；加入补偿后若仍假设40ms，制动阶段仍可触发倾角保护，因此不能只放开最大转速。当前80ms预设的三组用例通过，保护本身没有取消。

### 3.3 Yaw与切换

Yaw仍使用目标角加速度模型前馈、角速度PI和Euler／刚体耦合补偿；不是MPC。S1请求经过原入口就绪与确认，再以30°/s²限加速度进入自旋。S1回中走Braking，实测率小于2°/s且持续0.5秒，才进入Aligning；广义方向按原20°/s限速归并，之后普通模式重新持向。归并中重新加速会返回制动，真实保护锁止仍需落地、SA停机、低油门、S1回中解除。

## 4. 激光预测与观测

保留v5的前方窗口点亮、普通模式常亮及停机熄灭。在自旋中使用：

\[
\phi_{\rm laser}=\operatorname{wrap}\left[\phi+
(\dot\psi-\dot\psi_g)t_d\right].
\]

新增参数116为td，默认0，本轮初值4.5ms。来源是现有gyro一阶滤波B=0.1、dt=0.5ms时的低频延迟近似(1−B)/B·dt=4.5ms；在360°/s下约对应1.62°。这不是已测得的总系统延迟，不包含准确的IMU、融合、电平驱动或光电延迟；后续用实际相位观测调整。

GPIO14只有预测相位位于±1°时才允许点亮，200ms仍是最大脉宽而非固定时长。60 RPM全窗口约5.56ms，每圈约一次；200ms最小间隔不会阻止1Hz回访，2kHz检查在窗口内约有11个控制帧。波形3仍回传未预测的φ，离线应结合波形9、参考率状态51和参数116重建预测相位，不能因GPIO在原始φ窗口之外就直接认定误闪。

激光标记广义方位，仍不具备绝对磁航向或固定地面位置能力。事件次数包含首次对齐切入，不是圈数。低频GPIO卡可能漏看5ms脉冲，需同时看事件数／时刻与真实激光。

**退出验收未通过，暂缓升到30／60 RPM。** 目标率已降至0，但399–407秒记录的角速度仍有持续残差和波动，未连续0.5秒满足低于2°/s的停转条件。408.824831秒状态报告保护位16（制动超时），累计保护次数1，自旋入口锁止；410.576323秒因低油门1054µs复位普通模式，依旧没有`Aligning`阶段。该保护没有直接切电机；停机后锁止已按原条件解除，不能把解除锁止等同于完成了空中退出。
