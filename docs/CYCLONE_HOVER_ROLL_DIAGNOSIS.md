# 普通悬停横滚慢摆与 DShot 输出分辨率

## 实飞证据

对照 v11 记录 `18e9684085984998-18`，Teensy boot `3585516668`，选 160–209.75 s 的 4,975 个连续 100 Hz 波形。油门固定为 1317 µs，横滚、俯仰、航向均在中位死区，自旋未进入。飞手确认限位绳未到限位，观察到机体向右移动约 1–2 m 再回中。记录的主循环周期为 500 µs、最大工作耗时 303 µs、累计超时 0。

将横滚角与按 Euler 运动学换算的陀螺角速度去线性趋势、加 Hann 窗。约 0.14 Hz 处，融合横滚角幅值约 1.10°，陀螺分量换算角幅值约 1.24°。约 0.30 Hz 处分别为 0.67° 和 0.66°。两处均有机体角运动的证据。横滚需求力矩与角速度在 0.14 Hz 处相位差约 67°，说明请求力矩在该频带有顺着角速度的分量。它是闭环计算值，真实力矩取决于执行器。横滚积分可贡献同向分量，低频抗扰还取决于比例、阻尼和执行器动态。简化模型里降低积分会放大 0.14 Hz 外加力矩造成的摆幅，暂不据相位单独改积分。

固定油门段 M2、M4、M3 分别只出现 5、5、4 种实际下发码值。相邻变化均为 16 个 DShot 计数，分别跳变 588、568、693 次。v11 的飞行输出先将归一化命令转为旧 OneShot 的 125–250 整数刻度，再映射到 DShot。以当前名义推力曲线和 0.433 m 横滚力臂计算，悬停附近单台前电机的一档约为 0.019 N·m，与 0.14 Hz 处约 0.016 N·m 的横滚需求力矩幅值同量级。推力曲线是先验，数值用于比较分辨率，不当作实测力矩。

现有日志可以验证姿态和下发命令。真实转速、旋翼在载荷下的偏角和水平对地位置缺少观测，因此目前无法量化它们对单侧位移的贡献。慢摆起因也尚未唯一辨识。

## v12 改动和验证

RemoteMCU 飞行版直接把归一化电机命令映射到 DShot 码，悬停区最小步长从约 16 降到 1 计数。保持原停机门、起转最小码和 M2/M3/M4 线序。推力估算使用相同的线报码，保留 OneShot 和独立电机台架路径。保留 v11 控制器、入口门槛和保护。构建标识为 `drehm-cyclone-rotor-v12-dshot-resolution-20261119`。

合成模型验证用于检查停机、映射和闭环行为。用于筛选的模型没有复现本机持续低频慢摆，细化输出对位移的效果仍需实飞。

上电后先刷写和核对停机，再以 v11 的 0.80 航向外环、40 ms 电机时间常数和既有配平为对照配置。用相近油门的普通悬停，比较 0.12–0.45 Hz 横滚能量、码值分辨率与飞手观察的单侧往返。首次检查以普通悬停为限，先保留现有 15 RPM 预设。
