# v3 自旋进入确认及下一轮测试

本文保留v3设计与验证历史。本轮试验发现就绪资格闪烁，后续v4采用取得／保持双门槛及撤销计时，当前设计见[v4修正](CYCLONE_SPIN_ENTRY_HYSTERESIS_20261105.md)。

## 修改依据

用户确认最后一次机头已经稳定，稳定后才测试S1。本轮记录证明，更早一次CH6小幅偏离中位已进入Spin并触发跟踪误差保护；只收油不会清除锁止，导致最后一次满行程请求无效。见[原始诊断](CYCLONE_SPIN_RETEST_20261105.md)。本版处理这条进入链，不根据混合操纵日志盲改已能稳住机头的普通模式PI或动力学参数。

## 进入与拒绝流程

普通模式中，S1首次进入门槛由偏离1500µs超过50µs改为**超过150µs**，即低于1350或高于1650µs。已进入后仍按±30µs退出；停机时S1直接标定舵机的映射和解锁条件不变。

首次进入必须满足：S1已回中连续0.3秒；Yaw杆回中；普通模式控制趋势稳定连续0.5秒；随后S1超过进入门槛并保持0.3秒。慢慢旋过30–150µs过渡区不会丢掉已完成的回中准备。

趋势取实际航向率和上一帧物理Yaw控制器目标，分别作独立2Hz一阶低通。10°/s测试配置下，趋势率及目标各不超过5°/s、趋势率差不超过4°/s；同时要求瞬时航向率不超过10°/s、推力方向误差不超过5°。一般规则为：趋势率上限min(5,0.5×自旋上限)，趋势差上限min(5,0.5×跟踪保护阈值)，姿态误差上限min(5,姿态保护阈值)。这只是进入资格，不能作为转速稳定验收指标。

趋势判断避免瞬时短波动让肉眼已稳定的状态永远无法进入；不替换飞行PI或监督器使用的测量。首次无分配反馈时不能凭默认零值判定就绪。持续明显旋转、控制目标仍大幅纠偏、Yaw杆未回中，均不能通过进入资格。

过早请求、确认期间条件失效：保持普通模式，要求S1回中重新准备；**不产生自旋故障锁止，不在旋钮一直偏置时延迟自动启动**。正常进入时仍保留同一个物理PI的积分、目标限加速度、舵机状态与推力估计，不突然清零已建立的反扭矩补偿。

真正进入自旋后，超速、跟踪误差、倾角、分配和制动超时保护全部保持原值。真实保护触发后仍需落地、低油门、SA停机及S1回中，不能在空中拨旋钮解除。

## RemoteMCU 显示与实时预算

v3应用将入口状态59、锁止48和原因47放到状态卡最前。入口值：

| 数值 | 含义与操作 |
| --- | --- |
| 0 | 未进入有效控制油门，待机 |
| 1 | S1须回中重新准备 |
| 2 | 等待普通模式趋势稳定、Yaw回中 |
| 3 | 已就绪，可以请求自旋 |
| 4 | S1请求正在持续确认 |
| 5 | 已进入自旋／制动／归并控制路径 |
| 6 | 真实自旋保护锁止，查看47／48，落地后复位 |
| 7 | 自旋功能／模型未使能或未就绪 |

模式11仍表示0普通、1自旋、2制动、3归并；入口值5不单独代表仍在Spin。32路波形及参数ID保持原布局。新应用ID为`drehmflight-cyclone-rotor-v3`，新设备配置ID为`drehmflight-cyclone-rotor-device-v3`，旧录制仍保留其原Profile。低速状态卡可能跳过短暂的值4，模式／保护事件应同时看波形2／31。

新增一个uint32状态，完整STATE帧恰为512字节，仍适配现有单次有界USB写入，不扩大队列或每轮收发次数。入口只增加常数次标量运算和少量状态，复用已有推力方向误差计算；无动态分配、等待、Flash写入或新中断。目标周期仍500µs，通信350µs预算门槛及丢遥测策略保持。实际主循环耗时必须在下载后先以停机和飞行记录复核，不能仅凭编译或主机测试保证。

## 下一轮步骤

1. 通知上电后，SA停机、最低油门、S1及Yaw杆回中。通过RemoteMCU下载，确认build为`drehm-cyclone-rotor-v3-entry-20261105`，再选择v3显示配置。
2. 读回完整参数，并在停机状态恢复初始模型授权、飞行／自旋／激光开关，`model_verified=0`；自旋上限10°/s、加速度10°/s²、驾驶倾角5°。每次重启这些RAM授权会复位，不能漏做。
3. 先核对入口状态、保护位、遥控、IMU及主周期；开启原始录制，再由操作者普通模式起飞。S1及Yaw回中，机头稳住后等待入口3。
4. 单方向S1超过门槛并保持约4秒，不操作Yaw杆；本轮先观察约30–35°量级的转角，无需整圈。S1回中受控制动，安全落地、收油、SA停机。
5. 若入口1：回中、稳住后重新请求；若入口6：结束该轮并落地停机，不在空中复位。每次失败的起飞尝试后都切SA停机再准备下一次。
