# v4双向自旋与v5方向激光：部署、数据和结论

日期：2026-11-05。分支：`feature/cyclone-rotor-tricopter`。[本报告HTML版](reports/cyclone-v5-flight-20261105.html)。动力学、控制和接线见[模型文档](CYCLONE_ROTOR_MODEL.md)及其[离线公式版](reports/cyclone-rotor-model.html)。本次没有新增大旋转翼，也没有改变普通／自旋共用的物理力矩闭环。

## 1. 结论与边界

v4入口滞回后已实际进入双向约10°/s自旋。用户认为转速过慢且未观察到激光；10°/s本来就需要36秒一圈，两段自旋均未回到广义前方零相位，旧实现只在过零时触发、最长10ms，能够解释该次没有事件的记录。

v5将试验上限提高到30°/s，保留10°/s²加速度与原保护；激光改为进入前方窗口即点亮，允许已经对齐的模式切入事件。实测单方向Spin持续约41.19秒，稳态平均−29.56°/s，激光累计4次。用户反馈“看起来一切正常，包括激光也正常”。这支持本轮速度提升及方向标记功能已经实现。

当前仍不是全部验收完成：稳态瞬时率为−39.20至−21.25°/s，推力方向误差峰值6.46°，尚有波动；回中后进入制动并显著减速，但随后降油门复位为普通模式，日志没有完整的Braking→Aligning→Normal空中过程。下一轮应保持30°/s，验证反方向与完整退出，再考虑更高转速和广义多轴操纵。

日志没有高度和位置观测，模式时长不等于已知空中时长；激光事件不是物理光电延迟测量，估计航向也不是独立地面角度真值。

## 3. v5：窗口激光与30°/s配置

激光采用GPIO14，高有效，普通模式解锁时常亮、停机熄灭；自旋、制动及参考系归并期间，只有包角相位位于窗口内才允许高电平。进入窗口或对齐时切入相位模式触发一次；离窗、故障、无效样本立即拉低，达到脉宽上限也拉低。同次访问不重复触发，冷却期间错过的访问不在窗口内补发；取消原来的5°/s最低率门槛。正反转均支持，±180°不会误认为前方。

| 参数 | v4本轮值 | v5本轮值 |
| --- | --- | --- |
| 82 最大自旋率 | 10°/s | 30°/s |
| 83 最大角加速度 | 10°/s² | 10°/s² |
| 84 激光半窗口 | 2° | 1° |
| 85 最大脉宽 | 10ms | 200ms |
| 86 最小触发间隔 | 100ms | 200ms |
| 97 自旋驾驶倾角上限 | 5° | 5° |

200ms是上限，不是每次固定点亮时长；稳态30°/s通过完整2°窗口约66.7ms。初次对齐进入时可能点亮至200ms上限。固件默认最大自旋率仍15°/s，默认激光半窗口仍2°，试验预设只驻留RAM。首次模式切入也计数，所以4次点亮不能直接解释为4圈。标记的是估计的广义前方；没有位置闭环，平移、倾斜与高度变化都会移动地面光斑。

预设：`docs/remote-mcu/cyclone-v5-test-parameters.json`。应用ID沿用 `drehmflight-cyclone-rotor-v3`，revision2将GPIO、事件数及时间置顶，保持32波形／59状态／109参数／8窗口，已安装并在记录Profile快照回读确认。

软件验证：21项主机程序全部通过ASan/UBSan；双向10／30／90°/s、720°扫相位均只在前方窗口有时限点亮。新增±30°/s、10°/s²刚体仿真采用实际160ms舵机滞后而控制器估计80ms，惯量比例0.5／1／2的峰值率分别32.06／31.35／33.44°/s，推力方向误差峰值5.01／5.14／6.01°，均无保护。这些是合成模型结果，不是实机结果或惯量辨识。

Teensy4.0 usbserial构建通过，FLASH代码93424字节，RAM1变量37472字节，RAM2变量12416字节；既有CRSF架构标记、未使用磁力计变量和TFMPlus复制警告仍存在。

## 5. v5数据分析

先按boot隔离，再按源序号排序去重；完整日志逐帧校验CRC。本轮全记录无序号缺样，因此稳态统计没有以插值掩盖遥测空洞。Agent进程累计网络丢样数包含此前会话，不能拿累计值代替本次记录的完整性。

| 阶段 | 飞控时钟 | 解释 |
| --- | --- | --- |
| 普通模式与入口 | 记录开始–728.543秒 | 720.565秒低频状态已为就绪3，728.543秒进入Spin |
| 顺时针自旋 | 728.543–769.733秒 | 持续约41.19秒，估计航向累计−1170.19°，约3.25圈 |
| 回中制动 | 769.733–773.723秒 | S1回中，目标率平滑降至0，实际率减小并围绕零波动 |
| 低油门复位 | 773.723秒 | 物理闭环退出、模式复位普通；未观察到Aligning |
| SA停机 | 776.307秒低频状态 | 已停机、三电机零命令、激光低电平；最终状态同样确认 |

稳态窗口选择734–768秒，避开起始加速和旋钮回中段，共3400点，无缺样。该段油门恒1248µs，Yaw恒1500µs；Roll输入1503µs、Pitch约1500µs，属于杆基本回中测试。

| 指标 | 实测结果 | 含义 |
| --- | --- | --- |
| 目标／平均航向率 | −30.00／−29.56°/s | 平均幅值为目标98.5%，约12.18秒一圈 |
| 瞬时率范围 | −39.20至−21.25°/s | 存在周期及瞬时波动，不能称为严格匀速 |
| 率跟踪RMSE／绝对误差95分位 | 3.22／6.24°/s | 整段实际率与同帧目标率比较，未滤掉高频误差 |
| Roll／Pitch绝对峰值 | 6.37°／5.14° | 是姿态估计，不能证明位置不漂移 |
| 推力方向误差峰值 | 6.46° | 相比v4小角度测试更大，值得在提高转速前复核 |
| 舵机PWM范围 | 1463–1481µs | 没有持续大行程扫舵迹象，不等于已测得舵机真实动态 |

| 全启动累计最大工作／周期 | 299／500µs | 低频状态中的2kHz累计峰值，超周期计数0 |
| 控制故障／自旋保护次数／IMU拒绝 | 均0 | 没有达到各监督器的连续时间触发条件 |

瞬时率曾越过35°/s监督界线，但保护按连续0.25秒判定，不能据“未保护”声称没有过冲；本轮也没有为提高速度而放宽保护。

激光事件的飞控目标时刻为728.536595、742.522595、754.821095、766.590095秒。第一次为切入自旋且对齐时的窗口访问，后续三次为整圈回访，与估计累计约3.25圈一致。后两次回访间隔约12.30和11.77秒，围绕30°/s对应12秒周期。低频GPIO状态同时捕捉到部分高电平，用户独立观察激光正常；实际脉宽和相位精度仍没有仪器测量。

回中制动段持续约3.99秒。目标率约771.88秒到0，实际率随后围绕0波动；773.723秒因降油门退出物理闭环，连续低于2°/s并稳定0.5秒、进入Aligning再归并的完整链路没有得到本轮实证。可以确认减速行为，不能把地面复位当作空中退出成功。

## 6. 下一轮与复核命令

保持本轮参数，先反方向30°/s单轴测试；再单独记录S1回中后的足够稳定时间，观察模式1→2→3→0，并由操作者确认真实停转与机头方向。空间或姿态不允许时以落地优先，不能为等待软件状态强行延长飞行。两方向及完整退出通过后，再验证自旋中的广义Pitch／Roll／Yaw，最后考虑提高自旋率。

先不依据这一条闭环数据重估惯量或推力曲线：模型预计力矩来自同一模型，不是独立力矩测量；没有准确离地标注、推力／转速测量和外力约束信息，不能把闭环残差直接当作真实气动参数。

```sh
python3 tools/cyclone/inspect_recording.py \
  build/cyclone-v5-laser-test-20261105/laser-v5.rmplog \
  --metadata build/cyclone-v5-laser-test-20261105/stopped.json \
  --boot 1773810754 --start 734 --end 768
```
