## 操作顺序与分段

下载后保持SA停机、油门最低、S1回中，先独立轻拨Yaw、Pitch、Roll并回中，确认左杆左右只改变CH1、右杆左右只改变CH4、右杆上下只改变CH2，三电机命令保持0。停机时Yaw杆不直接驱动舵机，CH6台架直控仍保留。

开启正式录制并保存参数GET后，再通知用户按以下顺序进行；操纵均采用短时小幅输入，避免同时混合多轴。离地时刻、落地时刻和绳索状态需由用户/视频确认，不能用电机是否旋转代替。

1. 油门平缓加到本轮可控状态，其他三轴回中，稳定约10秒，记录起转、系留离地及中杆Yaw保持。
2. Pitch前后各轻推1–2秒，各次回中后留3–5秒观察恢复。
3. Roll左右各轻推1–2秒，各次回中后留3–5秒观察恢复。
4. Yaw左右各轻推1–2秒，各次回中后留约5秒观察停止和保持，最后三轴回中约10秒。
5. 平缓落地、收油并切SA停机，报告本轮结束及明显异常，再保存原始录制与试后参数。

若条件只适合短段测试，可落地分轮完成，标注顺序。挂绳持续拉紧会改变响应，因此本轮报告描述该约束下的结果。出现明显发散或再次停转立即结束该轮；不在线修改空中参数。

## 分析报告内容

报告以实际硬件数据为依据，附操纵、姿态/角速度、航向目标与反馈、舵机及电机命令、主周期的时间对齐曲线；记录固件哈希、Build/Boot、Profile、参数修订、样本缺口及故障状态。各轴分别报告可识别片段、输入和响应方向、回中恢复时间/超调及跨轴耦合；只在有明确阶跃/稳态时计算相应指标，不把手动缓慢拨杆强行当成标准阶跃。

Yaw特别比较中杆航向差、回中后的额外转角、角速度响应、PWM指令变化和分配受限；没有外部角度参照时，仅报告IMU相对航向。舵机PWM及模型力矩不是实际舵角/力矩。油门没有高度或垂向速度观测，不报告定高、升降率或自由悬停效率；Roll/Pitch没有完整内环目标快照，不将原始杆值线性换算为精确闭环目标角来宣称误差。

本轮不从250g配重系留数据拟合自由飞行`Izz`、κ、阻尼或绝对推力尺度。报告区分“用户观感”“日志实测”“模型估计”“待确认”，参数调整只针对可重复、可辨识的问题。
