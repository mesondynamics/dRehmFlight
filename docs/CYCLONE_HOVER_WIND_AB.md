# 普通模式悬停：姿态抗扰与地面定点分开验证

ArduPilot 的 [Loiter](https://ardupilot.org/copter/docs/loiter-mode.html) 把水平位置误差变成期望速度，再把速度误差变成加速度与期望倾角；内层控制实际姿态和推力。这样飞机能在稳态风中保持一个非零迎风倾角，而不必预先测出风速。固定油门也不等价于高度闭环。项目目前在用的控制链是 `controlCyclone → CycloneControl::step → 力矩分配`，没有对地水平位置或速度输入。六轴 IMU 能感知倾角变化，但不能区分静止与匀速水平漂移。不要将积分 IMU 的结果当作地面位置，也不要把风中的固定偏移都写进机械配平。

## 本轮可实施的单变量试验

基线为 v10 记录 `18e95bc6eb887c40-e`。1336.46–1385.29 s 油门为 1319 µs，持续约 48.83 s；飞手目测约 1 m，有风，无位置真值。选择 1340–1360 s 作等长参考：Pitch 标准差 1.073°，Roll 1.290°，俯仰陀螺 RMS 5.876°/s，估计航向误差 RMS 7.480°。M2/M4/M3 的相邻 100 Hz 命令差 RMS 分别为 5.53/5.99/6.51 个 DShot 计数，不是电机实际转速。

用 `remote-mcu/normal-hover-pitch-damping-ab.json` 作为单项差异清单，而非整机参数导入文件。在停机状态回读构建、正常模式基线、配平与自旋禁用状态。若符合基线，只在 RAM 将 ID 93 从 0.050 调到 0.055；否则先恢复并核对已验证基线。+10% 是试验步长，不是辨识得到的最优增益。正负角速度会得到更大的反向修正，零角速度时该改动不增加配平；同时可能放大陀螺噪声。主循环代码、采样、遥测、Yaw、Roll 与 Pitch 积分保持原样。该参数由模式共享，测试期间不得启用自旋；随后还原再考虑其他模式。

开始新记录，保持普通模式和飞手控制，固定机位拍摄地面标尺和机头，记录风向、绳是否承重。只在自然出现稳态时比较，不追求固定油门数值，不为凑时长延长飞行。选首个可比的连续 20 s 悬停窗口（剔除起降）；分析脚本检查三轴中杆、油门范围、采样连续和非零动力，不凭命令推断是否离地。若无可比窗口注明本轮不可直接比较。峰值恶化、出现新高频抖动或操纵性变差就结束，停机后恢复 0.050。Pitch 波动下降且横滚、航向、执行器抖动无明显恶化才考虑保留；单次有风结果仅作筛选。没有视频位置尺度就只报告姿态，不报告抗风位移改善百分比。

```sh
python3 tools/cyclone/hover_ab.py flight.rmplog BOOT_ID START_S --seconds 20
```

## 如果目标是松杆后回到地面同一点

室外可采用经验证的 GNSS 位置与速度；近地可采用下视光流、对地测距和陀螺旋转补偿估计水平速度，再用局部位置外环。光流里程会累积漂移，持久绝对定点需绝对位置参考。参见 [ArduPilot 光流模式的限制](https://ardupilot.org/copter/docs/flowhold-mode.html)。本项目应先以只读遥测验证传感器安装方向、尺度、时间戳、延迟、质量和失效检测，再在普通模式加入带倾角/加速度限制及积分抗饱和的外环，失效退回现有姿态控制、不切断动力。先隔离验证普通模式，再讨论自旋中的坐标变换。本轮没有加入未经验证的导航反馈。
