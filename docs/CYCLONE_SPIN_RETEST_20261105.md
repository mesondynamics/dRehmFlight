# 2026-11-05 S1 无响应复测诊断

## 已定位的问题

**最后一次飞行中 S1 满行程仍无响应的直接原因，是较早一次尝试触发的自旋保护锁止仍然有效。** 并非本轮未打开 `spin_enable`，也不是 S1 始终没有进入控制链。

用户说明：较早几次尚未飞稳，还没有开始有意测试 S1；最后一次才明确操作 S1。分析因此以最后一次为主，较早事件仅用于追溯锁止来源，不将其当作成功的自旋试验。

后续用户明确补充：**最后一次机头已稳定，稳定后才进行S1自旋测试**。这与最后一次保护位持续为2、请求被锁止的诊断一致；不能把最后一次S1无响应归因于用户尚未稳住机头。普通模式前段的偏转记录与后段稳定的用户观察应分开描述。

本轮没有修改或下载固件，没有更改增益、机构标定、IMU 比例或保护条件。重启后按已用试验配置恢复 RAM 参数并回读，revision1→2；109项参数与首次自旋试验 revision3 的快照逐项一致。`model_verified` 保持0。

保护是有意保留的状态，不应改成空中反复拨 S1 即可解除。它只禁止再次进入自旋；触发时走闭环制动，继续姿态控制。最终再次进入普通模式也不能单独作为制动、归并或自旋验收通过的依据。

## 保护为什么会触发，以及仍未确定的部分

较早的进入发生在普通模式航向尚未稳住时。进入瞬间，物理 Yaw 控制器仍保留约+20°/s的普通模式纠偏目标，随后按限加速度连续过渡；该段实际航向率为−17.01至+9.49°/s，目标为+7.19至+19.99°/s。不能把这段当作固定10°/s的稳态自旋辨识。

最后一次前段、S1尚回中且Yaw杆回中时，普通模式已经出现明显负航向率，控制器请求正向纠偏，之后积分逐渐增加、航向才逐步收敛。因此，“S1进入被锁止”已经查明，**普通模式起飞偏转及此前转速波动的物理原因仍未唯一确定**。模型推力、反扭矩、机构受载、限位绳作用等需用隔离证据区分，不能凭现有闭环命令反推唯一原因，也不应将预测力矩当作测得力矩。

用户确认限位绳允许自由转动且测试时松弛；该信息按用户描述记录，不擅自归因于绳索，也没有使用停机时可能仍在晃动的数据写入陀螺零偏。

已结束的地面承托静止记录 `18e5113b4749df68-26` 中，GyroZ残余均值约−0.121°/s，明显小于本轮动力阶段数十°/s的变化；该次静止结果不足以解释本轮异常，也不能用它否定其他时刻真实转动或温漂。

## 下一轮操作和判据

1. 每次上电恢复并回读试验参数。SA停机、油门最低、S1及Yaw杆回中；确认 `spin_enable=1`、`spinReady=1`、保护位0、禁止标志0、IMU有效。
2. 每次失败尝试后都先安全落地，再收油、切SA停机并将S1回中；由遥测确认锁止清除，再开始下一次。只收油后重新推油门不足以复位。
3. 普通模式先稳住机头，再隔离S1测试。若普通模式仍持续自行转动或目标与实测率明显相反，先结束该轮，不进入自旋。
4. 初次仅一个固定S1方向约4秒，Yaw杆保持回中，随后S1回中减速、落地停机；10°/s并含加速时约30–35°只作观察参考，不要求完整转圈。
5. 分别核对进入、自旋率跟踪、保护、回中制动和归并。保护条件保持原值；出现保护后不以反复拨S1尝试重入。
