# v7：自旋停转判据、率环修订与实机复测

日期：2026-11-05。分支：`feature/cyclone-rotor-tricopter`。[HTML版](reports/cyclone-v7-stop-20261105.html)；[完整动力学模型](CYCLONE_ROTOR_MODEL.md)；[v6准备与15 RPM实测](CYCLONE_60RPM_PREPARATION_20261105.md)。v7已下载。提高率PI的首次实飞出现顿挫，已回退至1.5／0.4，用户复测反馈“这次效果不错”。随后完成一轮60 RPM级别实机记录；当前仍未完成完整动力学辨识和长期裕度验收。

## 1. 已知现象与结论边界

v6在15 RPM下两方向均能旋转，操作者反馈工作正常，并说明“S1回中后机体就不怎么旋转了”。顺时针固定目标段平均14.44 RPM，逆时针固定目标段平均13.49 RPM。逆时针回中后，目标率归零，但399–407秒航向率均值仍约6.59°/s，瞬时值有波动；未连续0.5秒满足逐帧低于2°/s的条件，随后触发保护位16（制动超时），没有进入归并阶段。

退出失败的控制逻辑路径已经确认；残差的物理来源没有全部辨识。停机后机体仍悬挂，不能用该段修改陀螺零偏，也不能把悬挂运动当成传感器故障。吊绳外力仍不加入本版动力学模型，IMU安装角及零偏均沿用已验证数值。

本次保留独立停转资格滤波，撤回实飞效果较差的强率PI。**单独滤波不会让持续6.59°/s转动满足2°/s停转条件。** 持续残差仍待辨识，不能根据操作者接近停转的观察直接宣告完整模式退出成功。

## 2. 停转资格与完整退出

普通／自旋控制的刚体、执行器、分配和广义坐标模型沿用v6。Roll/Pitch反馈、Yaw加速度前馈、耦合补偿、80ms电机滞后初值及激光预测均保留。仅停转资格采用独立1Hz低通趋势：

\[
r_{s,k}=r_{s,k-1}+\alpha\left(r_k-r_{s,k-1}\right),
\qquad \alpha=\frac{2\pi f_s\Delta t}{1+2\pi f_s\Delta t},\quad f_s=1\ {\rm Hz}.
\]

该趋势在飞行控制活动、收到上一控制帧的分配反馈时更新，首次初始化为实际率；低油门复位、停机或故障恢复时清零。自旋入口仍用原2Hz趋势。率PI和超速／跟踪／倾角／分配监督器继续使用原快速测量，没有把整个飞控率环改成1Hz。

有效停止阈值仍为min(参数100，最大自旋率的10%)。15 RPM阶段最大率为90°/s，60 RPM阶段最大率为360°/s；两阶段参数100均为2°/s，所以实际停止阈值均为2°/s。连续0.5秒同时满足以下条件，才从制动进入归并：

| 条件 | 本轮值或含义 |
| --- | --- |
| 停转趋势 | 绝对值低于2°/s |
| 瞬时测量包络 | 绝对值低于原跟踪误差阈值18°/s；越界立即清零资格 |
| 模式管理目标率 | 绝对值低于0.01°/s |
| 实际率环目标 | 上一帧分配反馈的目标绝对值低于0.1°/s |

阈值数值和连续时间保留，但停止测量定义已由逐帧值改为趋势；这是一项明确的资格逻辑变更。它允许小角度零均值振动，不允许持续低速转动被误认为停止。归并中若趋势超过停止阈值的1.5倍、瞬时包络越界或物理目标再次非零，返回制动。广义方向继续按20°/s归并，Yaw杆回中、方向对齐和停止资格均满足后返回普通模式。

制动超时、超速、跟踪、姿态及分配保护保持启用，保护请求闭环制动并锁止空中重新进入。原落地、SA停机、低油门、S1回中清除条件不变。本版没有提高停止率阈值、延长制动超时或取消保护。

## 3. 自旋率PI参数

物理Yaw力矩继续为惯量缩放的率反馈与积分，加上模型前馈和耦合补偿：

\[
\tau_z=J_{\rm eff}\left(K_p(r_{\rm target}-r_{\rm filtered})+I\right)
+\tau_{\rm ff}+\tau_{\rm coupling},\qquad
\dot I=K_i(r_{\rm target}-r_{\rm filtered}).
\]

公式中的率采用rad/s，惯量、积分限幅与抗饱和路径沿用现有实现。首次RAM预设曾把参数94的Kp由1.5改为4、参数95的Ki由0.4改为2.5。该候选虽通过理想模型，但实际15 RPM旋转顿挫，已在SA停机后回退至 **Kp=1.5、Ki=0.4**，修订号3，全部111项回读一致。固件默认值本来就是1.5／0.4，无需为回退重刷。普通模式仍使用原持向环和原增益。

增加增益会改变真实舵机滞后、量化和气动力误差下的稳定裕度，不能用理想仿真的较小误差直接替代实飞证据。本版不再恢复4／2.5。进入和回中仍保留30°/s²目标限加速度、积分状态、舵机限速和受限分配，不在模式切换时清空积分或跳变目标。

## 7. 60 RPM实机记录结果

记录 `18e51d8e6df712e8-72` 共15622个样本，缺样0、CRC错误0。模式在1046.809331s进入自旋，1060.399332s进入制动，1063.969319s回到普通模式；这是实际“普通→自旋→制动→普通”序列，低油门收尾后SA停机。

自旋目标最低−347.1°/s（约57.9 RPM），测得航向率最低−336.1°/s（约56.0 RPM），接近60 RPM目标。自旋段 Roll 标准差2.09°、Pitch标准差2.25°、推力方向误差峰值7.11°；用户评价整体可用但有轻微晃动，因此本轮保持参数不变。自旋与制动阶段出现分配保护位8，状态57累计1次；保护未切断电机，继续执行闭环制动。最终状态为故障0、超周期0、最大工作350µs、周期500µs，激光事件计数20。

该记录证明当前控制链路可以把无大翼三旋翼带到接近60 RPM并回到普通模式，但不能证明惯量、阻尼、推力曲线、执行器滞后已经辨识完成，也不能证明在没有分配保护余量时可以长期运行。实机调试按用户要求暂时暂停，下一步先基于该记录辨识晃动与分配余量的来源，再决定是否调整模型或参数。
