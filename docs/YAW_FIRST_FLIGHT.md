## 落地后的辨识

以现有三臂几何计算：

```text
G(t) = Σ [(r_i × e_ti)_z T_i sinδ_i]
H(t) = Σ [σ_i T_i cosδ_i], σ = [-1,+1,-1]
Izz * dωz/dt = G + κH - Dωz
Δωz = a∫Gdt + b∫Hdt - c∫ωzdt
a = 1/Izz, b = κ/Izz, c = D/Izz  （推力尺度已固定时）
```

`tools/yaw/analyze_flight.py`是纯Python标准库的离线工具。输入RemoteMCU导出的CSV、该段真实参数快照，以及人工确认的自由飞行时间段；不以电机转动代替离地判定。它从实际DShot重建推力及电机滞后，使用回传舵机位置估算，做0.3s分段积分回归，避免直接差分放大陀螺噪声。保持到达顺序；会话重启、重复、倒序、序号缺口或大时间缺口均不跨段拟合，断段后丢弃0.5s执行器恢复区间。近水平且未电机饱和的数据才入选。

```sh
python3 tools/yaw/analyze_flight.py flight.csv \
  --parameters actual-parameters.json --boot-id 123456 \
  --airborne 35.0 42.0
```

时间参数是目标时间戳秒数，不是电脑时间。示例数值应替换为实际离地/落地时间。需要足够长的独立小激励：仅回中悬停通常不足以辨识全部三项，工具会返回数据不足；首轮仍可先评价航向保持、指令抖动、配平和周期。拟合用前70%片段训练，后30%验证，列归一化QR检测独立激励；报告只产生候选值，不下发参数。

未确定推力尺度时，拟合的惯量/阻尼以当前推力表为条件。若真实推力是表的`s`倍，则`a=s/Izz`，仅Yaw数据不能独立分离`s`和`Izz`。工具另报告已确认近悬停片段的`mg/Fz_model`公共尺度候选，需要结合垂向加速度、电量和姿态复核。三路独立推力曲线/κ需要额外激励或台架数据；共同齿轮和单次悬停不能支持无约束同时拟合。先修正公共推力尺度、反扭矩配平和有效Yaw响应，再逐轮调整惯量及阻尼。参数仅在落地停机后更新，并复读记录。
