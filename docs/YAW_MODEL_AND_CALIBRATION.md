## 角度定义：请按这个方向测量

“桨盘偏转角” `δ_i` 指**桨盘法线／电机推力轴，相对机架竖直方向的倾角**。不测单片桨叶的安装螺距角，也不把 270°舵机轴角或 PWMServo 逻辑角当成桨盘角。

采用右手系 FLU：原点在重心，`+X` 朝机头（M2、M4之间），`+Y` 朝机体左侧，`+Z` 垂直机架基准面向上。航向及偏航力矩的正方向均为**俯视逆时针／左转**。

每个电机的径向单位向量为 `e_ri`，逆时针切向为 `e_ti=e_z×e_ri`。在切向倾转平面内，指向桨盘上方的推力轴为：

```text
n_i = cos(δ_i) e_z + sin(δ_i) e_ti
δ_i = atan2(n_i·e_ti, n_i·e_z)
```

| 电机位置（俯视） | 0° | 正角度时，推力轴顶端偏向 |
| --- | --- | --- |
| M2 左前 | 垂直机架面 | 机体左后方 |
| M4 右前 | 垂直机架面 | 机体左前方 |
| M3 正后 | 垂直机架面 | **机体右侧** |

最方便的首轮基准是 M3：**向右倾为正、竖直为零、向左倾为负**。站在机尾面向机头时，观察者右侧就是机体右侧。三个电机的正倾角都会增加逆时针偏航推力矩。

```text
俯视，机头向上                  M3 切向截面，从机尾看向机头

            +X 前                           +Z 上
        M2       M4                             ↑  / 推力轴
             O                                  | /  δ3 > 0
  +Y 左 ←                                     M3────────→ 机体右
            M3
```

量角以机架基准面为准：摆平机架，量电机轴或与桨盘平行的刚性量角面，不把机身侧翻、柔性桨叶弯曲计入倾角。历史记录称“PWM 增大，M3 向左倾”，因此预期 `dδ3/dPWM<0`，请用本次实测核对。`CH6=1500` 只是软件中位，**不要把此处的实测角强制归零**。机械零位与抵消反扭矩所需的飞行配平位不同。

估计器内部是 FRD（前、右、下），FLU 向量／角速度转换为 `(x,-y,-z)` 后进入 FRD。模型全部使用 FLU；航向控制使用现有四元数导出的航向变化率，不直接把倾斜时的 GyroZ 当作航向变化率。

## 已实现的模型与控制

### 几何、动力和约束

`TricopterDynamics.h` 用三个独立9点表描述 `δ_i=f_i(s)`，节点为舵机逻辑50、60…130；线性插值、禁止外推。每个电机用5点推力曲线描述 `T_i=g_i(u_i)`，节点为归一化命令0、25%、50%、75%、100%，并提供反查。首点为停机零推力，低速运行死区需用实测验证；正常控制只在油门超过现有有效控制阈值时启用。

当前几何支持120°径向机臂、各自力臂长度、水平重心偏置及转子相对重心的共同高度；切向方向按 M2/M4/M3 分别定义。若实际转轴不是径向、存在明显径向倾转、各转子高度不同或中心随倾转移动，应扩充位置／轴向模型后才能飞行，不能用这一版假装拟合。

`Q_i≈κ_iT_i` 表示反扭矩大小。`σ_i` 是**机体受到的反扭矩**符号，与转子转向相反。历史实测 M2 CCW、M4 CW、M3 CCW，对应 `σ2=-1, σ4=+1, σ3=-1`，硬件变更后重核对。

```text
F_B = Σ T_i n_i(s)
τ_B = Σ [ r_i × T_i n_i(s) + σ_i κ_i T_i n_i(s) ]
m a_W = R_BW F_B − m g e_z
I ω_dot + ω × (Iω) = τ_B + τ_dist
```

代码计算完整三轴力和三轴力矩，包括倾斜反扭矩对横滚／俯仰的影响，并提供刚体角加速度函数。气动阻力、转子陀螺瞬态和推力台未覆盖的效应仍属于模型误差，需要通过试验检查。

共4个独立执行器（三电机＋联动舵机），不能任意独立控制六个力／力矩。当前分配 `[Fz,τx,τy,τz]`，侧向合力是需要观察的耦合量。[1]

### 推力相关的 Yaw 分配

共同物理倾角、水平等高臂的简化式为：

```text
Fz = Σ T_i cosδ
τz = Σ L_i T_i sinδ + Σ σ_i κ_i T_i cosδ
```

Yaw 第一项来自**三个**桨盘的切向推力。不能套用只有尾电机倾转的三旋翼混控。ArduPilot 尾倾转实现的最大偏转、饱和标志和 `1/cosδ` 升力补偿可作参考，机构几何仍须重新推导。[3]

若先分配竖直分力 `Fzi`，`Az=ΣL_iFzi`、`Cz=Σσ_iκ_iFzi`，则 `δ=atan((τz_sp−Cz)/Az)`、`T_i=Fzi/cosδ`。相同推力和相同κ下，抵消两逆一顺反扭矩的配平满足 `tanδ_trim=κ/(3L)>0`，不是固定物理零位。

实际代码不要求三个倾角相同：对候选舵机位置，先用完整模型解3×3方程，保持竖直力、横滚及俯仰力矩，再用最多两步有界 Newton 修正求 Yaw；一次Yaw求解最多5次模型评估。舵机位置求解200Hz，传感器／航向反馈和三电机分配仍为2kHz：在两次Yaw求解之间，用当前舵机目标重新解3×3方程，避免把横滚／俯仰电机目标保持5ms。约束包括逻辑50–130、三处真实倾角上限、舵机变化率、非负推力和每电机推力上限。

电机上限不允许直接独立截断：实现中对三路力矩／升力解作共同缩放，保持其比例，并报告 `liftScale`、Yaw残差和受限标志。共同缩放会损失升力和姿态控制幅值，不能称为严格的轴优先级优化；其可接受范围必须实测验证。无可行解、奇异矩阵或非有限值触发故障停机及重新准备，不在2kHz环内无限迭代。

### 航向外环与角速度 PI

`NormalYawControl.h` 的链路为：

```text
CH4 → 航向目标 ψ_sp → 航向 P → 限速／限加速度的航向变化率
    → 角速度 PI → 需求偏航力矩 N·m → 控制分配 → 标定表／舵机
```

进入有效控制时锁存当前相对航向。左杆左右形成航向变化速度；回中时按当前速率和允许减速度计算一次可达的停止航向，再保持该目标。角差使用±180°最短差，限制目标超前角；外扰后返回保持目标。停机、低油门、故障和退出普通模式复位。普通模式与旋转参考仍分开；`spin_enable` 默认关闭，后续旋转验证另行进行。

率环使用滤波航向变化率、PI、可选阻尼前馈、条件积分和有限反算抗饱和。估算舵机滞后及µs命令量化，显示模型预计力矩；抗饱和反算仅在分配受限时使用可实现力矩，不把普通执行器滞后直接反算进积分，避免稳态航向偏差。上述均非实际力矩反馈。角速度 PI 先按近水平 `Izz` 模型设计；大倾角的全惯量／航向映射耦合尚未辨识，先限制普通模式试验姿态范围。默认增益只用于合成回归，未调好本机。

仅有 MPU6050 时，重力不能提供绕竖直轴的绝对航向观测。先做有限时间相对锁头并量化漂移；长期地面绝对方向保持需要独立航向观测，如经干扰验证的磁力计、双天线GNSS或视觉。PX4无磁航向方案依赖额外GNSS速度和运动激励，不能直接用于只有六轴IMU的静止悬停。[4]

**本版参数仅应用到RAM，重启回到源码默认值；设备保存请求明确拒绝。** Teensy EEPROM模拟写入可能触发Flash编程／擦除，不能在500µs主循环内保证完成。标定数据确认后写入源码默认值并提交；之后如需持久保存，应独立设计明确退出飞行循环的维护流程，不能把同步Flash写入藏在参数回调内。

`safe_to_flash` 要求未解锁、SA停机、低油门、CH6回中且三电机命令停机；它是工具状态检查，不是Teensy核心的硬件烧录互锁。CH6扫角离开中位时该状态变为0属预期行为，不会关闭标定控制。隔离电机台架生成器使用 `DREHM_REMOTE_MCU=0`，保留旧文本协议及台架安全限制。

## 主循环预算与验证边界

遥测在执行器输出后运行，不使用采样ISR、不分配堆内存、不等待USB；每轮最多读取32字节、尝试发送一个完整帧。目标接收载荷上限144字节（16项SET的最大长度），超长帧头立即拒绝，避免错误流触发1KiB整帧校验与扫描。队列不够则丢样／延后管理帧，前段用时超过350µs则跳过通讯。Yaw求解固定次数、200Hz运行；非Yaw求解轮仍更新率环、估算及2kHz电机分配。参数写入只在停机处理，禁止Flash／EEPROM写入，波形启停不会停止飞控。

上述设计控制工作量，但**编译和主机测试不能证明实板最坏执行时间**。下载后需在100Hz、1kHz、连续参数读／写、断网／重连、失联和闭环负载下检查：`LOOP_US`、最大工作、通讯／新Yaw最大耗时及超时增量。目标是持续500µs周期且无超时；若最坏预算不足，先降低下传／分配频率或把管理计算拆成更多小步，不能用放慢主循环掩盖问题。原始RMP记录还要独立检查丢包与时间序号。
