## v4 资格获得、保持与请求确认

S1回中0.3秒、取得稳定资格0.5秒、明确离中超过150µs以及持续请求0.3秒的流程仍然存在。变更是：取得资格后，使用更宽的保持范围，并对保持范围外的短时波动做0.25秒撤销计时。它不会无限保留过时资格。

实际率和上一帧物理目标仍分别使用入口专用2Hz低通。下表为本轮最大自旋率10°/s、超速裕量5°/s、跟踪保护8°/s、姿态保护8°的配置：

| 条件 | 获得就绪 | 已就绪后的保持范围 |
| --- | --- | --- |
| 实际率趋势绝对值 | ≤5°/s | ≤8°/s |
| 物理目标率趋势绝对值 | ≤5°/s | ≤8°/s |
| 两个趋势之差绝对值 | ≤4°/s | ≤8°/s |
| 推力方向误差 | ≤5° | ≤7° |
| 当前瞬时航向率绝对值 | ≤15°/s | ≤15°/s |
| 计时 | 范围内连续0.5秒取得 | 范围外连续0.25秒撤销 |

获得门槛的一般规则仍为趋势率min(5,0.5×自旋上限)、趋势差min(5,0.5×跟踪保护)、倾角min(5,姿态保护)。保持范围为趋势率min(8,自旋上限)、趋势差min(8,跟踪保护)、倾角min(7,姿态保护)。瞬时率上限取“自旋上限＋现有超速裕量”，替代v3把任何大于目标上限的瞬时值都当作不稳定的处理。

在保持范围内，3状态不再因较小的普通模式纠偏立刻变为2。越出保持范围不足0.25秒时保留资格，但**S1确认计时暂停，也不能在范围外的当帧进入Spin**；恢复范围内后继续确认。连续越界0.25秒撤销资格；若当时S1已偏置，则拒绝该请求，要求回中。最初就未取得资格的请求仍立即拒绝，保持旋钮偏置不会等到以后自动开始。

Yaw杆离开中位立即撤销进入资格。停机、低控制油门、故障及真实自旋锁止仍复位入口；真实保护的落地、SA停机、低油门及S1回中解除条件不变。

100Hz原始数据的近似资格重放可产生约8–10秒的连续可用窗口，用于检查滞回方向是否合理；它缺少2kHz中间样本，不能替代实际固件或飞行验证。S1始终回中，因此本轮也没有真正的自旋请求可重放。
