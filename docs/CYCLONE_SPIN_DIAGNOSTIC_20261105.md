# 2026-11-05 低速自旋首次试验诊断

## 结论

普通模式水平安装角补偿后，用户反馈“现在好很多了”，随后开启低速自旋试验。用户最终澄清：**左杆左右能够调整实际 Yaw，S1 没有观察到明显的持续自旋，姿态稳定**。此前“S1能调Yaw、左杆效果不明显”的描述已经撤回，不能据其作结论。

本轮证明了 S1→自旋请求→目标转速→执行器命令的软件链路被调用，但**没有通过实际持续自旋、转速稳定性或回中停转验收**。记录中出现超速保护和制动超时，不能把平均转速接近目标或模式最终回到普通，写成控制成功。当前未找到可以直接修改增益或动力学参数的唯一原因。

本轮没有修改飞控源码、增益、模型、保护或烧录固件。停机后将 RAM 中 `spin_enable` 从1改为0，revision3→4，并回读确认；`flight_enable=1`、初始估计模型和激光开关保留，`model_verified=0`。完整参数及原始文件位于忽略目录 `build/cyclone-spin-20261105/`。已告知用户可断电，后续硬件访问须重新核实在线状态。

## 控制链与事件顺序

S1在普通飞行时通过偏离中心的滞回阈值请求自旋；进入Spin后转为航向率控制。S1决定机体目标航向率，Yaw杆调整广义前方参考方向。共享的物理Yaw控制器保留率环积分，采用模型加速／阻尼前馈、PI反馈、力矩逆分配及舵机／电机滞后预测；Roll/Pitch继续控制推力方向。

10°/s稳定转速对应36秒一圈，2–3秒只对应20–30°，还未计入加速阶段。因此“没有完整转圈”不能单独说明没有响应；但用户明确反馈S1效果不明显，必须用独立方向标记和隔离输入再核实。

按当前约定，低PWM S1为正率、俯视逆时针；高PWM为负率、俯视顺时针。是否实际向某侧旋拧仍以接收PWM和实物方向共同核验，不能仅靠录制名称。

超速条件为实测航向率绝对值超过10+5=15°/s，持续0.25秒。触发后本轮自旋禁止重新进入，S1继续满行程也不会恢复；须满足停机、低油门和S1回中等条件才能复位。制动继续控制三轴姿态，不直接因自旋保护切掉全部电机。

Spin段估计航向由+13.545°变为−68.402°，净变化约−81.948°。这是陀螺参与积分的估计结果，**没有独立外部航向观测，不能用它推翻用户“S1无明显自旋”的反馈**。当前证据排除了“软件始终未进入Spin”，没有排除物理执行效果、传感器残差、初始转动及模型参数失配等因素。

激光相位脉冲计数为0。本段未完成一圈，相位只由接近0向负方向推进，且低于相对5°/s时本就不发相位脉冲；不能单独据此认定激光硬件故障。

## 停机测量复核及其边界

自旋后一个未独立确认机体静止的停机窗曾有约−5.7°/s的Z读数。用户按要求固定静止后，1476–1481s窗口的Z均值约−0.532°/s、标准差0.039°/s，没有复现该大读数。不能把之前的−5.7°/s直接写入校准，也不能认定已经发现恒定零偏。

用户随后执行停机手动逆时针转向，最初描述“约90°”，再次确认实际是**目测约120°、没有实际测量**。选取1919.000318–1929.990318s窗口：1100样本、无缺样，油门恒1000µs、三电机命令恒0，估计净航向增加143.464°。方向符合本项目正Yaw定义，但手动角度没有独立量具，**不能据此拟合比例因子或宣布陀螺量程正确／错误**。整个357秒记录的累计航向变化包含长时间漂移与搬动，不能当作该次手动转角。

后续1965–1970s窗口三电机仍为0，Z均值−0.056°/s、标准差0.585°/s、范围−1.408至+1.233°/s；接近零均值不等于噪声为零或整个会话无温漂。当前1°/s连续0.5秒的停转门槛与这些波动有关联，需要专门复核，不能仅为了进入Aligning而放宽门槛。

停机核验整条记录中另有1696.29–1696.64s约0.35秒非零电机命令。因此只使用已明确列出的全零电机窗口核对手动转向，不能把整个文件称为全程无动力标定。没有根据这段改变安全逻辑。

## 下一轮顺序

后续已完成用户明确为120°的往返核验，结果见[120°航向核验](CYCLONE_YAW_ANGLE_CHECK_20261105.md)。去程估计+114.910°、回程−117.278°；方向与角度量级相符，但静置残余变号，未据此写入比例修正。标定期间飞行和自旋授权均关闭，不能把本次停机核验当作自旋复测通过。

1. 用机头对准地面两个已知夹角的标记，在SA停机、三电机命令0时核对转角、符号及转动前后静止读数。陀螺比例／零偏尚无可靠标定，不自动更新。
2. 核验测量后，隔离S1与Yaw操纵：Yaw杆回中，普通模式先稳定、停止已有转动，再短时只给一个固定S1方向，记录物理转角与软件目标／实测率；不以“是否完整转一圈”作为唯一判据。
3. 若再次有保护，记录首个触发条件，安全落地后分析；不放宽保护或加大速度掩盖问题。根据标注清楚的响应，逐项辨识执行器增益／滞后、推力与惯量组合，再调自旋PI和前馈。
4. 单方向转速跟踪、制动及归并通过后再验收反方向、连续多圈与相位激光。没有位置／速度反馈，不宣称绝对原地定点。
